# Madad — Emergency SOS & Ambulance Finder (UX Concept)

Interactive demo of the Madad concept: one-tap emergency SOS for Pakistan.

**Try it:** open `index.html` in a browser.
1. **Home** — Press and **hold the SOS button for 3 seconds** (hold-to-activate prevents false alarms). Quick-call chips for Rescue 1122, Edhi 115 and Police 15, plus nearby hospitals with live ICU bed counts.
2. **SOS countdown** — 3-second cancel window; location is shared with verified ambulances and your emergency contacts.
3. **Pick ambulance** — verified services with fixed PKR fares (Free / Rs 1,800 / Rs 3,500), live ETAs, ratings, and a family auto-notify toggle.
4. **Live tracking** — accelerated simulation: ticking ETA, progress bar, crew card with vehicle plate, blood-type chip, destination hospital bed hold, SMS confirmation to family.
5. **Receipt** — trip summary with reference number and total fare.

Built with plain HTML/CSS/JS — no frameworks. Part of Abbas Momand's UI/UX portfolio series of apps solving major real-world problems in Pakistan.
